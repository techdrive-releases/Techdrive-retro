# TechDrive Retro

TechDrive Retro is a collection of free legacy builds of
TechDrive designed for older versions of Microsoft Windows.

This package contains builds made for classic Windows systems.

---

## Included Builds

### TechDrive 95

Compatible with:

- Windows 95
- Windows 98
- Windows ME
- Windows 2000

### TechDrive XP

Compatible with:

- Windows XP 32-bit
- Windows XP 64-bit
- Windows Vista 32-bit
- Windows Vista 64-bit

---

## Important Note

TechDrive Retro is provided as a free legacy build.

These builds are intended for older Windows systems and may
not provide the same features as newer versions of TechDrive.

Always keep backups of important files.
